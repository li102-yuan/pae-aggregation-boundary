# Reproducing every figure and table

Environment: CPython 3.13 with `numpy`, `matplotlib` and `pymupdf`; the exact versions used for
the shipped artefacts are pinned in `requirements.txt`. Install with
`python -m pip install -r requirements.txt`. No model calls and no network access are needed.

## 0. One command

```bash
python analysis/fig_w72.py
```

Rebuilds all three figures (SVG + PDF) and all three tables, and asserts, on every run:

- `FIG_TEXT_GATE=PASS` — no CJK character, no internal data path and no `55.88` in any
  figure (checked on the SVG text nodes and on the PDF text layer);
- `B4 ... [PASS]` — frame width 3.30 in, smallest glyph 7.00 pt, for each figure;
- `PDF self-check: ... PASS` — TrueType subset embedded (`/FontFile2`), no Type 3 fonts.

The run ends by printing the sha256 (first 16 hex) of the nine generated files.
Re-running is byte-identical: timestamps are cleared and `svg.hashsalt` is fixed.

## 4. Frozen specifications

`configs/w11spike/{inputs,prereg,grid}.json` with `FREEZE_W11SPIKE.sha256`;
`configs/w11geom/PREREG_GEOM.json`; `configs/w11airline/PREREG_AIRLINE.json`.
Verify with `sha256sum -c FREEZE_W11SPIKE.sha256` from inside `configs/w11spike/`.

The frozen files are the pre-registration of the gates (30% benign misfire, 90% coverage on the
two field families, 10% unmatched, 24 bit / H 0.5) and of the candidate grid. They are reproduced
byte-for-byte as signed before the runs, including their original working-language annotations;
`FREEZE_*.sha256` pins them, so they are not translated or reformatted.

## 5. What is not included

Full per-call JSONL logs (`runs/`) and the per-pair records of the 104-pair construction matrix
stay in the authors' private archive and are available from the corresponding author on request.
Every number in the tables and figures can be recomputed from the CSV files shipped here;
`analysis/tau_pair_matrix_summary.md` supplies the aggregate readings of the construction matrix.
The three trailing annotation columns of `analysis/w11airline_grid.csv`
(`c2_note`, `c3_detail`, `c4_detail`) are editorial notes; no table or figure reads them.
