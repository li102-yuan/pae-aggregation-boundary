> 窗 `W11.3`｜2026-11-05｜**零实验**（只读 `analysis/w11spike_grid.csv`；`G2`／`W6.2`／`W10.1` 的读数二手引用）

## 0. 结论

> **定理 1 的一句话版**：若一个防御器的判定只经两件事依赖——（a）本次调用**抹掉归属后**的记录，（b）对历史做的**序不敏感标量累计**——则它在任意 τ 对上、对任意阈值都必然同判（同拒或同放）。判别力只能来自**归属**（片段属于哪个 cell），不能来自"记得更多"：定理对状态空间与判定函数不作任何可计算性、有限性、单调性限制。

三个数：

| 量 | 值 | 含义 |
|---|---|---|
| 归属盲机器的**判别率**（逐对：两臂判决不同） | **0**，任意 `θ′` | 定理 1；对任意 τ 对，两臂**逐步**同判（不只是整段同判） |
| `K_B` 的判别率 | **104/104** 拦、**0/104** 误拒 | 反例校验（§6.1）：区间并集是归属敏感的，故**出**定理范围 |
| `S3/D1` vs `S1/D1` 的 `F7` | **0/20** vs **20/20** | 同 `lineage`／`matcher`／`θ′`，**只换 `scope`**：归属粒度即判别力的载体 |

**这不是"所有跨调用防御都不可能"。** 定理的补集是"归属敏感"，而 `K_B`（每 cell 区间并集）与 `S1/D1`（每 cell 覆盖）都在补集里，且都能判别（`104/104`、`20/20`）。本文件与 `W11.1` 的分工是：**必要条件**（本文件）vs **不充分性**（`W11.1` 命题 1）。§7 给出一张共用的"判据族能力格"，§7.3 列出三条措辞禁令。

## 2. 定义

### 2.1 片段、调用、抹除

一个**片段** `f` 是一条六元组

```text
f = ( k(f), o(f), len(f), ch(f), enc(f), ς(f) )
```

`k(f)` 是 cell 键 `(entity_id, field)`（与 `c1` §1.3 的键同一物）、`o(f)` 是声明偏移、`len(f)` 是字节长、`ch(f)` 是通道、`enc(f)` 是编码、`ς(f)` 是内容（字节串或其规范摘要）。一次**调用** `c_i` 是片段的有限多重集；`c_{1..i} := (c_1, …, c_i)`。

**抹除**（本文件唯一的新算子）

```text
erase(f)  := ( len(f), ch(f), enc(f), ς(f) )          # 抹掉 k(f) 与 o(f)
erase(c)  := ⟦ erase(f) : f ∈ c ⟧                     # 多重集像
```

抹掉的**恰好是归属**：片段被记到哪个 cell、落在该 cell 的哪个偏移。留下的四元组是"这次调用送出了什么字节、走哪个通道、用什么编码"。**`ς` 被保留**——这一点在 §6.3 很关键：内容本身**不是**判别力的来源，把内容用来**反推归属**才是。

### 2.2 τ 对（τ1–τ3，逐条对应窗口 T1 那句话）

称 `(b, m)` 是一对**长度 `n ≥ 2` 的 τ 对**，若

| # | 条件 | 可判形式 | 对应窗口／数据 |
|---|---|---|---|
| **τ1** | **逐调用抹除相等**：`erase(c^b_i) = erase(c^m_i)`，`∀ i ≤ n` | 逐 `i` 比较两个多重集（长度／通道／编码／内容逐字节） | 窗口 T1"历史仅差前 `n−1` 片"的**形式化**；实测 `W6.2`：两臂逐调用出站内容**逐字节相同 104/104** |
| **τ2** | **末次全等**：`c^b_n = c^m_n`（含 `k` 与 `o`） | 逐 `i = n` 比较六元组多重集 | 窗口 T1"最后一次调用逐字节相同" |
| **τ3** | **归属分歧**：`m` 的全部片段落在同一 cell；`b` 的片段两两落在不同 cell | 比较 `⟦k(f) : f ∈ c_i⟧` 的基数 | 构造事实：危险臂单实体、良性臂 `k` 实体（`W6.2` §"唯一差别是实体归属"） |

τ1 说"两臂的字节流相同"，τ3 说"两臂的归属不同"，τ2 说"最后一次连归属也相同"。三者合起来正是窗口 T1 括号里那句"最后一次调用逐字节相同，历史仅差前 `n−1` 片"——**差的是归属**，不是字节。

> **注 2.2（τ3 不是定理的假设）.** 定理 1 只用 τ1。τ2／τ3 用于把"τ 对"钉成一个非空、且与构造一致的对类；τ3 还用于命题 2 的见证（§4）。

### 2.3 机器（防御器 `F`）

一个防御器是一个五元组 `F = (A, e, ⊕, ū, F_dec)`，满足

| # | 条件 |
|---|---|
| **D1** | `A` 是**任意**集合（有限、可数、不可数皆可），`e ∈ A` 是初始状态 |
| **D2** | `ū : Frag → A`，逐片段更新（**允许**读取 `k(f)`／`o(f)`；"盲"是下面单独加的条件，不是公理的一部分） |
| **D3** | `⊕ : A × A → A` 可交换、可结合、以 `e` 为单位元；`u(c) := ⊕_{f ∈ c} ū(f)` |
| **D4** | 判定在提交之前：`d_i := F_dec(c_i, A_{i−1}; θ′)`，`θ′ ∈ [0,1]` 是 `F_dec` 的**任意**参数 |
| **D5** | `d_i = allow ⟹ A_i := A_{i−1} ⊕ u(c_i)`；`d_i = deny ⟹ A_i := A_{i−1}` |

**D1–D5 是"序不敏感累计器"的形式定义**（闸门 1），比窗口的"标量加法"**宽**：取 `A = ℝ^d`、`⊕ = +`、`e = 0`、`ū(f) = (len(f), 1)` 就是"总交付字节数＋调用计数"（`d=1` 即单标量）。`⊕` 可交换使 `A_i` 只依赖多重集，这就是"序不敏感"；`⊕` 可结合使"逐片段更新"与"逐调用更新"一致。**D4／D5 不是外加的工程假设**：它们逐条对应 `gate.py::replay` 的既有语义（判定在 `L164–169`、提交在 `L178–180`，拒绝时 `committed` 不动），见 `c1` §1.4。

**归属盲**（本文的核心谓词，**不是**公理，是要单独检验的假设）：`F` **归属盲**，若它的全部输入都只经 `erase` 依赖片段——即 `ū` 经 `erase` 分解（存在 `ū̄` 使 `ū(f) = ū̄(erase(f))`），且 `F_dec` 的第一个参数是 `erase(c_i)`。等价说法：`F` 的判定序列只经 `erase(c_{1..i})` 依赖输入。

### 2.4 与 `c1` 的 `D` 的关系

给定 `D` 与初始 `committed`，`replay` 是确定性的 ⇒ 每个 `D` 诱导一个机器 `F_D`。反过来不成立（机器比 `D` 宽）。`F_D` 的归属盲性**完全由 `scope` 决定**：

| `scope` | `F_D` 的状态键 | 归属盲？ |
|---|---|---|
| `S1` | cell `k` | **否**（键就是 cell） |
| `S2` | 实体 `e`（`Σ_{k∈e}` 聚合） | **否**（键是实体，比 cell 粗但仍是归属） |
| `S3` | 无（`Σ_k` 求和后只剩一个比值） | **是**，但**仅当**交付区间集合无重叠且跨 cell 坐标不相交——引理 5.1 |

这张表是 §7 能力格前三行的代码依据，也是 §6.2 那组对照实验（`C031`／`C037`／`C049`）的解释：**只换 `scope`，就是把 `F_D` 从归属敏感搬到归属敏感的更粗一级、再搬到归属盲。**

## 3. 定理 1（归属盲 ⇒ 不可判别）与证明

> **定理 1（τ 对不可判别）**
> 设 `F` 满足 D1–D5 且归属盲，`(b, m)` 是满足 **τ1** 的 τ 对（长度 `n ≥ 2`）。则对任意 `θ′ ∈ [0,1]` 与任意 `i ∈ {0, 1, …, n}`，
>
> ```text
> A^b_i = A^m_i        且        d^b_i = d^m_i        （d^b_0 := ⊥）
> ```
>
> 特别地：两臂的判定序列**逐调用相同**，故整段判决同拒或同放，且"首拒调用号"相同。

**证明.** 对调用序号 `i` 归纳。

*基（`i = 0`）.* 由 D1，`A^b_0 = A^m_0 = e`。

*步（`i−1 → i`）.* 归纳假设 `A^b_{i−1} = A^m_{i−1}`。由 τ1，`erase(c^b_i) = erase(c^m_i)`。由**归属盲**，存在 `F̄_dec` 使

```text
d^b_i = F̄_dec( erase(c^b_i), A^b_{i−1}; θ′ ),      d^m_i = F̄_dec( erase(c^m_i), A^m_{i−1}; θ′ ).
```

两个实参分量逐一相等（第一个由 τ1，第二个由归纳假设），`F̄_dec` 是函数，故

```text
d^b_i = d^m_i.
```

分两种情形：

1. `d_i = deny`。由 D5，两侧状态不动：

```text
A^b_i = A^b_{i−1} = A^m_{i−1} = A^m_i.
```

2. `d_i = allow`。由 D5 与 D3，

```text
A^b_i = A^b_{i−1} ⊕ ( ⊕_{f ∈ c^b_i} ū(f) ),        A^m_i = A^m_{i−1} ⊕ ( ⊕_{f ∈ c^m_i} ū(f) ).
```

`A_{i−1}` 两侧相等（归纳假设）。内层折叠：由归属盲 `ū = ū̄ ∘ erase`，故内层等于 `⊕_{f} ū̄(erase(f))`，它是同一个 `ū̄` 在同一个**多重集** `erase(c^b_i) = erase(c^m_i)` 上取值（τ1），故内层相等。`⊕` 是函数，故 `A^b_i = A^m_i`。

归纳完成。 ∎

**注 1（不需要 τ2，也不需要 τ3）.** 证明只用了 τ1 与 D1–D5。τ2（末次全等）是窗口那句话里最强的一条，但它对结论**不承重**：若末次全等，则连归属敏感的机器也无法在末次调用上分开两臂；而定理说的是——归属盲的机器**连前面 `n−1` 次都分不开**。这一点必须写明，否则读者会以为定理是"末次全等"的推论。

**注 2（这不是资源界）.** `A` 可以是任意集合（D1），`F_dec` 可以是任意确定性函数（不要求可计算、不要求单调、不要求有限内存）。故结论**与"记得更多"无关**：把 `A` 从 `ℝ` 扩到 `ℝ^{10^9}`、或给 `F_dec` 无限算力，判别率仍然是 0。缺失的是**不变量**（状态落在"抹掉归属"的等价类里），不是资源。反过来说，这也解释了为什么"加长历史窗、加细计数器"这一整类补救都不改变结论。

**注 3（"序不敏感"不是承重条件；反例就在本仓）.** D3 的可交换性在证明里只用于让"多重集求和"良定义；**真正承重的是归属盲**。去掉归属盲、保留"标量加法＋序不敏感"，定理立刻为假：

```text
A_k := Σ_{ j ≤ i , d_j = allow }  Σ_{ f ∈ c_j , k(f) = k } len(f)     # 每 cell 一个标量（只累计放行，符合 D5）
F_dec := deny ⟺ max_k A_k / field_len[k] ≥ θ′
```

这是 `A = ℝ^{|K|}` 上的标量加法、可交换、序不敏感——但它在任何满足 τ3 的对上**能**判别：危险臂的 `A_{k₀}` 长到 `L`（比值 1），良性臂每个 cell 只拿到 `L/n`（比值 `1/n < θ′`，对 `θ′ > 1/n`）。**这个反例不是假想的**：在 τ 对的构造几何下（连续切片、无重叠），它与 `S1/D1` 的 `cov(k)` 逐调用相等，实测 `F7 = 20/20`（`C031`）。

故正确的类是「**标量 ∧ 归属盲**」，不是「标量」。窗口 T2 把边界写成"标量 vs 区间"，在这条边界上**各取了一个代表元**（`K_A` 的总字节 ↔ `K_B` 的区间并集），但两者都不是边界本身：per-cell 标量（上式）是一侧的第三个点，且它站在"能判别"那边。§9 披露 2 记此更正。

## 4. 命题 2（归属敏感足以判别；见证不需要阈值）

> **命题 2（最小见证 `R★`）**
> 定义
>
> ```text
> R★ :  d_i = deny  ⟺  ∃ k ∈ K : |{ f ∈ c_1 ∪ ⋯ ∪ c_i : k(f) = k }| ≥ 2
> ```
>
> 则对任意满足 τ1–τ3 的 τ 对（`n ≥ 2` 且每次调用非空），`R★` 在 `m` 上于 `i₀ ≤ 2` 拒绝、在 `b` 上全程放行；故 `R★` **判别**该对。`R★` 不使用 `θ′`、不使用区间、不使用内容、不使用任何累计量。

**证明.** 由 τ3，`m` 的全部片段落在同一 cell `k₀`；由 `n ≥ 2` 与"每次调用非空"，到第 2 次调用结束时 `k₀` 上的片段数 `≥ 2`，故 `R★` 在 `i₀ ≤ 2` 拒绝。由 τ3，`b` 的片段两两落在不同 cell ⇒ 任一 cell 的片段数 `≤ 1` ⇒ `R★` 全程放行。两臂判决不同 ⇒ 判别。 ∎

**注 4（判别力 ≠ 可用性）.** `R★` 在真实良性写上的代价是**全部**：良性任务把同一字段分片写是常态（`W11.4` 的五档写几何——整字段／1/2／1/4／1/8／≤3 B——全部如此），"同 cell 收到 ≥2 片即拒"会把它们全拒掉。故命题 2 只证明**判别力可达**，不证明**可部署**。这条区分就是 §7 能力格的两列；把它抹平会得到一个假结论——"既然 `R★` 能判别，那判别不难"。

> **注 5（命题 2 的作用是定位，不是候选）.** 它把"判别力"这个量从"覆盖率够不够细"里剥出来：判别只需要**归属**这一个 bit，不需要 `θ′`、不需要测度、不需要内容。于是 `W11.1` 的整个机器（`cov(k)`、`θ′`、`K(θ′,L)`）都不能被解释为"为了判别"——它们是为了**记账**（交付了多少字节）。这个剥离是 §7 缝合的前提。

## 5. 引理 5.1（`S3/D1` 在该族上的分划不变性）

> **引理 5.1.** 设一次 episode 已交付的区间集合 `I` 满足：(a) 同一 cell 内无重叠；(b) 不同 cell 的区间位于各自的偏移空间，作为 `(cell, offset)` 对互不相交；(c) 各区间不越出 `field_len[k]`（此时 `c1` §1.3 的截断是惰性的）。则
>
> ```text
> Σ_k cov(k)  =  Σ_{f ∈ I} len(f)
> ```
>
> 与 `I` 到 cell 的**分配无关**。从而 `S3/D1` 的 `coverage = Σ_k cov(k) / Σ_e entity_capacity[e]` 在该族上逐调用等于"已交付总字节 ÷ 全库容量"，即一个满足 D1–D5 且**归属盲**的机器（`A = ℝ`，`ū(f) = len(f)`，`F_dec`：比值 `≥ θ′` 即拒）。

**证明.** 由 (a)，`cov(k)` 是 cell `k` 内区间长度之和（无重叠 ⇒ 并集测度＝长度和）。由 (b)，对 `k` 求和即对不相交的坐标空间求和，故等于 `Σ len`。分母 `Σ_e entity_capacity[e]` 由状态存储决定，与本次交付的分配无关。 ∎

**注 6（引理 5.1 的前提是本族的构造事实，不是普遍事实）.** 前提 (a) 在 τ 对的两臂上都成立：危险臂是连续切片，良性臂每个 cell 只有一个片段。若攻击者**重复**送同一段字节，`Σ_k cov(k)` 会因跨 cell 不去重而偏大，引理不成立——那时 `S3` 已不在定理类里，定理对它沉默（`W10.2` 的 `F4` 正是这一方向：区间并集的必要性）。故引理 5.1 **只**用来解释 §6.2 的那三行读数，不得外推成"`S3` 恒为标量"。

## 6. 反例校验与边界

### 6.1 `K_B` 能判别：定理的边界在"归属"这一侧

`K_B` 的状态是 `posted`——**按 cell 分组的区间集合**，判定是 `coverage ≥ θ`（`c1` §1.4）。它**满足** D1–D5：区间并集是可交换、可结合、以 `∅` 为单位元的折叠（`A = (2^{Intervals})^K`，`⊕` 逐 cell 求并）。它**不**归属盲：`ū` 读 `k(f)` 与 `o(f)`。故**出**定理 1 的范围。实测：在 `W3.3`／`W6.2` 的 104 对上 `K_B` **拦 104/104、误拒 0/104**。

> **这一点很关键**：`K_B` 满足 D3 说明**"区间"不是分界线**——它被排除的**唯一**理由是读归属。若照窗口 T2 的"标量 vs 区间"写法，读者会以为"把区间换成标量就能被定理覆盖"；真相是"把 `k(f)` 从状态里删掉才会被覆盖"，而删掉之后判别力就归零（定理 1），不删则定理沉默但能判别（本节的 104/104）。

| 判据 | 判别率（逐对，两臂判决不同） | 是否在定理 1 的类里 |
|---|---|---|
| 任意归属盲机器（任意 `θ′`） | **0** | 是 |
| `K_B`（每 cell 区间并集，`θ=0.55`） | **104/104** | 否（状态是 cell 索引的区间集） |

这就是闸门 4 要的反例校验：定理**不是**空的——它排除了一整类真实存在的判据（总字节、调用计数、通道配额、全库比率），同时把 `K_B` 这类**能判别**的判据留在补集里。定理的边界因此不是"能不能拦"，而是"**拦的信息从哪来**"。

**一处必须写清的替换**：窗口 T2 要求把边界写成"标量 vs 区间"。`K_B` 确实落在"区间"一侧，且确实能判别——但把"标量"当作另一侧的**定义**会出错（§3 注 3 的 per-cell 标量反例）。精确表述是：

```text
定理的边界 = 归属盲（状态只经 erase 依赖输入）  vs  归属敏感（状态按 cell 索引）
"标量 vs 区间" 是这条边界上的两个代表元，不是边界。
```

### 6.2 边界两侧的受控读数：只换 `scope`

`analysis/w11spike_grid.csv` 里有三行，`lineage=L3`、`matcher=M1`、`unmatched=allow`、`denom=D1`、`θ′=0.55` **全部相同**，**只有 `scope` 不同**：

| 行 | `scope` | 误拦（68 任务） | `F1`（72 对） | `F7`（20 对） | 归属盲？ |
|---|---|---:|---:|---:|---|
| `C031` | `S1`（每 cell） | 39/68 = 57.4% | 72/72 | **20/20** | 否 |
| `C037` | `S2`（每实体） | 39/68 = 57.4% | 72/72 | **0/20** | 否（比 cell 粗） |
| `C049` | `S3`（全会话） | 15/68 = 22.1% | 72/72 | **0/20** | 是（引理 5.1） |

三行读数是本文最有说服力的一段实测：

1. **`F1` 三行全同（72/72）**——这只说明危险臂都被拒了，**不说明两臂被分开**（§6.4）。`F1` 是**拦截**而非**判别**，把它当判别力的证据是本仓表格最容易出错的一处。
2. **`F7` 从 20/20 掉到 0/20**——`F7` 是"同实体第二已注册字段"，一旦 `scope` 比 cell 粗，分母换掉，判别力归零。**归属粒度就是判别力的载体**，这是定理 1 在数据侧的指纹。
3. **误拦不随 `F7` 一起降**：`S2` 的误拦与 `S1` **完全相同**（39/68），而 `S3` 降到 15/68 是**用 `F7 = 0` 换的**（`c1` §5.1 的同一论证）。⇒ "换粗粒度降低误拦"是拿判别力做的交易，不是免费的改进。

### 6.3 三类"不在定理范围内"的累计器（闸门 3，窗口 T2 要求）

窗口 T2 要求显式列出不适用的累计器，否则读者会以为定理在说"所有跨调用历史状态都不行"。逐条给**它的实际地位**——"不在定理范围"与"能判别"是两件事：

**(1) 序敏感（时间窗／滑动窗）.**
`⊕` 换成"最近 `m` 项"或"窗内求和"，D3 不满足 ⇒ 不在定理的**陈述**里。但**结论仍成立**：窗的选取规则只读抹除后的记录（调用序号或时刻），在**同步节奏**下（同一 harness、同一调用序列）两臂的窗内容逐调用相同 ⇒ 同判。故本文件把它记为**"定理未覆盖、结论同类"**，并明确**不**把它算作反例。这也是它与 (2) 的分界：它读的是**时间**，不是**归属**。
**边界如实记**：若两臂的**节奏本身**不同（同一调用序列被拉长／压缩），时间窗的选取会不同，那时窗能"分开"两臂——但那是**时序侧信道**，不是 τ 对（τ 对的定义 τ1–τ3 里没有节奏项）。这条**不在**本文件任何结论的覆盖范围内。

**(2) 集合／区间型（`K_B` 的区间并集）.**
状态是 `k ↦ 区间集`——D1–D5 它**都满足**（§6.1），只在"归属盲"一处出范围。**它真的能判别**（§6.1 的 104/104）。这是定理唯一的"正面反例"，也是其边界的实证锚点；同时它也证明"区间型"不是被定理排除的**理由**（理由只有归属）。

**(3) 带内容的指纹（`M2`／`L3`）.**
这一条要分两层说，混为一谈会得出相反结论：
- **内容本身在 `erase` 里**（`ς` 被保留）⇒ 只用内容"记住见过什么"的机器**仍属定理类**，仍不可判别。所以"加了内容指纹就能判别"是**错的**。
- **一旦指纹被用来反推归属**（把片段认回原字段，即 `L3`），状态就变成 cell 索引 ⇒ 出范围。但方向与 (2) **相反**：它把两臂的片段认回**同一个**原字段，覆盖率在两臂上**同步**累加 ⇒ 判别力**下降**（两臂同判），代价是误拦不降。机制上与 `C001`→`C031` 的对比同向（`F1` 0/72→72/72，误拦 38/68→39/68）——**但这条对比混了两个因子**（`L1|none` → `L3|M1`，归属与匹配器同时变），故不能把差值全记在归属上。
  **如实标注**：这一层是**机制论证**，本窗零实验、未逐对测量"`L3` 下两臂是否同判"，故不得作为定理的推论引用。

### 6.4 一条方法学推论：分划盲判据的"高拦截＋低误拦"可以恒真

> **推论 6.4.** 设 `F` 归属盲。则对每个 τ 对，`deny_any(m) = deny_any(b)`（定理 1 于 `i = n`）。故在**同一** τ 对总体上，"`F1` 拦截率"与"逐对良性臂被拒率"**恒相等**。

这条推论对论文的表格有直接影响：本仓的 `F1`（分母 72 对）与"误拦"（分母 68 个 holdout 任务，`benign_n=68`）**来自两个不同总体**。于是对任何归属盲判据，"`F1 = 72/72` 且 `误拦 = 15/68`"这种并列是**恒真**的——它只说明该判据在两类不同负载上各拒了一批，不说明它分得开两臂。`S3`（`C049`）就是这种情形：由引理 5.1 它在**本族**上归属盲，故其 `F1 = 72/72` 蕴含"逐对良性臂 72/72 也被拒"——**这个量本表没列**，只能由定理推出。

**建议（交 `W7.2`）**：凡报 `F1` 必同时报**逐对**量 `disc := #{对 : d(m) ≠ d(b)} / N`。本仓唯一现成的样本是 `K_B` 的 `104/104`（`0/104` 误拒）。缺 `disc` 时，`F1` 与"误拦"的并列必须标"**不同总体**"，否则读者会把"拒了两个不同总体"读成"分得开两臂"。

## 9. 披露（五条，含对窗口文本的三处更正）

1. **窗口 T1 的假设与它自己的 τ 对定义冲突（更正 1）.** 窗口写"若两臂的每次调用在 `(effect, labels, state)` 上**逐次相同**"。但 τ 对的定义是"历史仅差前 `n−1` 片"，而差的就是 `state`（归属）；若 `state` 逐次相同，两臂就是同一条轨迹，"不可判别"退化为"同一输入同一输出"——定理变得**空**，且对真实的 104 对**一对都不适用**。本文件把假设换成 **τ1**（逐调用**抹除归属后**相等），定理才既非空、又覆盖真实对。这是**收缩假设方向**的更正：`erase` 后的相等比逐次全等**弱**，故结论更强。

2. **窗口 T2 的边界"标量 vs 区间"说窄了（更正 2）.** `K_B` 确实在"区间"一侧且能判别，但"标量"**不是**归属盲的同义词：per-cell 标量（§3 注 3）是标量、可交换、序不敏感，却**能**判别（本仓 `S1` 的 `F7 = 20/20` 就是它的读数）。正确的边界是"**归属盲 vs 归属敏感**"，"标量 vs 区间"只是这条边界上各取的一个代表元。若照窗口字面写，会得到一句**可被单个反例推翻**的定理。

3. **窗口 T2 的"`i = k` 时当前调用相同"是 τ2 的特例（更正 3）.** 本文件的归纳对**每个 `i`** 成立，不需要 τ2。τ2 的真实作用是让归属敏感的机器也无法在末次调用上分开两臂——那是 `K_B` 一侧的事实，与定理 1 无关。照窗口的写法（只在末次用"当前调用相同"）会漏掉"前 `n−1` 次也分不开"这一半，而那才是定理的分量所在。

4. **`S3` 的"两臂同判"是推导，不是本窗测量.** §6.4 的"`C049` 的 `F1 = 72/72` 蕴含逐对良性臂 72/72 被拒"由引理 5.1 ＋ 定理 1 推出。本窗零实验，未新增 `disc` 列；`W7.2` 若引用必须标"**推导**"，不得写成"实测"。

5. **`C3` 行的"可判别＝是"缺单独跑行.** 表里 `C3`（每 cell 标量）的判别标"是"，依据是"本对几何下与 `S1` 的 `cov(k)` 逐调用相等"——**几何论证，不是独立测量**；"不可部署"一侧用的 `C031` 是**代理读数**（`S1` 的区间并集），严格说 `A_k = Σ len` 这条规则本身没跑过。若 `W7.2` 要把 `C3` 单列成一行，须另开窗跑该规则（约半天，属新实验，本窗无权限）。
