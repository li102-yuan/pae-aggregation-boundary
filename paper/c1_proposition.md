# C1 命题化：加性 per-cell 覆盖判据族在 H1–H4 下的空可行域

> 窗 `W11.1`｜2026-11-05｜**零实验**（只读 `analysis/w11spike_frontier.csv`、`analysis/w11spike_grid.csv`、`src/spike/w11_matching/gate.py`）
> 依据：`D-024` §五（三段回写）、`D-025`（换赛道；`C1` 升 co-headline；五项口径）、`D-026` §三（H1 的检验改由 `W11.4` 承担）
> 口径：本文件一律用 `D-025` §五的改名——`H` = **partial-leakage fraction**；"残熵" = **均匀独立 hex 假设下的标称剩余不确定性**；"拦截率" = **structural interception rate**。`24 bit` 是**运行判据**，不是安全强度、不是条件熵、不是猜测熵。

## 0. 结论

**在 H1–H4 四条明示假设下，不存在阈值 `θ′` 使「①良性误拦 ≤30%」与「⑤拦截后标称剩余不确定性 ≥24 bit 且 `H` ≤0.5（逐 episode）」同时成立。** 证明只用到两件事：判据的**记账结构**（引理 1／1′）与**阈值可行性函数的上确界**（引理 4）。`234` 组扫描**不参与证明**，只作实例化对照。

三个数：

| 量 | 值 | 含义 |
|---|---|---|
| `1/2 + 1/(2R)`，`R = 24/4 = 6` B | **`7/12 = 0.5833`** | ⑤ 允许的 `θ′` 上确界（对 `L` 取上确界后仍成立） |
| `θ*`（本负载 ① 的最小可行 `θ′`） | **`1.00`** | 六档网格上唯一 `误拦 ≤30%` 的点（`11/68 = 16.2%`） |
| `θ* − 7/12` | **`0.4167`** | 两腿的间距；不是"还差一点" |

**这不是"该族不可能"**。它是一句带条件的话：**若**良性写几何使 ① 需要 `θ′ ≥ θ*`、**且**秘密是单字段的、**且**归属可靠、**且**字符独立均匀、**且**判据按单字段容量记账（H1–H4），**则**该族在此负载上买不到两者的同时满足。任一条不成立，命题不适用（§3.1 逐条给反例方向）。

## 1. 判据族的形式化（与 `gate.py` 逐行对应）

### 1.1 元组

一条判据是一个八元组

```text
D = (scope, denom, lineage, matcher, norm, unmatched, dest, θ′)
```

取值与含义**逐字取自** `gate.py::Rule`（L28–37）：

| 维 | 取值 | 语义（代码位置） |
|---|---|---|
| `scope` | `S1`／`S2`／`S3` | 单字段／同实体跨字段／全局会话（`_ratios` L119–137） |
| `denom` | `D1`／`D2` | 范围内字段总容量（朴素）／`truth_len`（oracle）（L128–131、L134–137） |
| `lineage` | `L1`／`L2`／`L3`／`L3c` | 无归属／oracle 归属／内容推断归属／L3+声明一致优先（`attribution` L96–114） |
| `matcher` | `none`／`M1`／`M2`／`M2-null`／`M2-short` | 归属来源；`M1` 持明文（不可上线）、`M2` 指纹 `ℓ_min=8`、`M2-short` `ℓ_min=4`（`matching.py` L200–208） |
| `norm` | `declared`／`all4` | 匹配前归一化范围 |
| `unmatched` | `allow`／`deny` | 内容匹配不到时：回落声明坐标／直接拒（L106–109、L164–165） |
| `dest` | `off`／`chan`／`cell` | 目的地授权；`cell` 要求片段落在声明 cell 内（L154–157、L166–167） |
| `θ′` | `[0,1]` | 判定阈值（**候选网格参数**，不是部署 `θ=0.55`） |

### 1.2 归属（`attribution`）

一次调用由若干片段组成；片段 `frag` 带声明坐标 `key()`、`offset`、`length`，以及真值坐标 `true_entity`／`true_field`／`true_offset`（攻击者不可见）。归属函数

```text
attribution(frag, D) → ([(key, off, len)], status),  status ∈ {struct, oracle, matched, unmatched, fallback}
```

- `L1`：返回声明坐标，`status=struct`（L99–100）。
- `L2`：返回真值坐标，`status=oracle`（L101–102）。
- `L3`：`hits = matcher.locate(content, encoding)`（L105）；空则按 `unmatched` 处置（`deny` → `([], "unmatched")`；`allow` → 回落声明坐标，`status=fallback`），否则返回**全部**候选（`status=matched`）。
- `L3c`：若 `hits` 中含自身的 `key()`，只返回自身那一条（L110–113）；否则同 `L3`。

### 1.3 覆盖率（`_ratios`）

记 `posted[k]` 为当前调用为止、归属到键 `k` 的区间集合（`replay` L147 拷 `committed`，L158–159 追加本次 `hits`）。记 `cov(k) = _covered_bytes(posted[k], field_len[k])`：区间先合并（`history.py::_merge` L159–170，闭开区间，重叠与相接合一），再**截断到 `field_len`**（L173–180）。未登记键在 `_ratios` 里被 `cells` 过滤掉（L118、L89–93）⇒ 覆盖率为 0。

| `scope` | 覆盖率的定义（L117–137） |
|---|---|
| `S1` | 对每个已登记 cell `k`：`cov(k)/field_len[k]`；`coverage = max_k` |
| `S2`／`D1` | 对每个实体 `e`：`Σ_{k∈e} cov(k) / entity_capacity[e]`；`coverage = max_e` |
| `S2`／`D2` | 同上但分母换 `truth_len`（oracle） |
| `S3`／`D1` | `Σ_k cov(k) / Σ_{e∈entities} entity_capacity[e]`，单键 `"*"` |
| `S3`／`D2` | 同上但分母换 `truth_len`（oracle） |

`entity_capacity[e]` = 该实体**全部已登记字段**容量之和（L198–203）。

> **「加性 per-cell」的确切含义**：在**单个 cell 内**，已覆盖字节是**并集测度**、按字节**相加**（`cov(k)` 是测度而不是布尔命中）——这正是它能被 `field_len[k]` 除、能形成阈值比较的前提；**跨 cell 取 `max` 而不是求和**，是 `S1` 与 `S2`／`S3` 的分界线。命题只覆盖「分母是单 cell 容量、跨 cell 取 max」这一族；`S2`／`S3` 把分母换成实体／会话容量后，`max` 与求和都不再对应单字段，命题不适用（§5.1）。

### 1.4 判定与提交（`replay`）

```text
deny  ⟺  (∃ 片段 status = unmatched 且 unmatched=deny)      # L164–165
       ∨  (dest 违规)                                        # L166–167
       ∨  (coverage ≥ θ′ − 1e−12)                            # L168–169
```

放行时 `committed ← {k: _merge(posted[k])}` 且本次片段计入 `delivered`（L178–180）；拒绝时 `committed` 不动。整段结果里的 `delivered_truth_bytes` 是 `delivered` 中**真值键等于 `episode.truth_key`**的片段真值区间并集、截断到 `truth_len`（L182–184），`H = delivered / truth_len`，`intercepted = (delivered < truth_len)`（L191）。

> **"覆盖判据"的精确定义**（窗口 T1 要求的一句）：`deny ⟺ coverage_{s,denom}(posted) ≥ θ′`，其中 `posted` 由 §1.2 的 `attribution` 按 `lineage` 生成、`coverage` 由 §1.3 按 `(scope, denom)` 计算。**上面三条分支里的前两条（`unmatched`、`dest`）不属于覆盖判据**，它们是独立的拒绝通道；本命题只讨论覆盖通道，并利用"额外通道只会增加拒绝"这一单调性（§5.2）。

### 1.5 两条工程语义（必须写明，否则命题与代码不符）

1. **`ε = 1e−12` 在本数据上是惰性的**：覆盖率取值落在 `1/L` 的格点上（`L ≤ 40`），六档 `θ′` 是两位小数有理数，除精确相等外 `|coverage − θ′| ≥ 1/40 = 0.025 ≫ 1e−12`；精确相等时 `ε` 使拒绝**包含**等号（保守方向）。故本文用严格形式 `coverage < θ′ ⟺ allow`。
2. **未登记键 fail-open**：`_ratios` 的 `cells` 过滤使未登记键贡献 0 覆盖率 ⇒ 声明到未登记键的片段"免费"。这与部署件 `K_B` 在未登记标识符上的 fail-closed（`W10.2` 的 `F2`／`F3`）**不同**；本文按 `replay` 语义写，且在 §5.2 说明该差异不改变空域结论（fail-closed 只会更严）。

## 2. 引理

以下恒设载荷的真值落在**单一字段** `f`（长 `L`，单位字节），并设

> **H2 归属可靠性（A）**：一次调用投递的每个真值片段，其归属区间落在 `f` 上（即按内容记账，不按声明漂移）。

### 引理 1（单次最大放行长度）

设 `D` 的 `scope=S1`、`denom=D1`、`dest=off`，H2 成立。则任一被放行的调用交付的真值字节数 `h` 满足

```text
h ≤ ⌈θ′L⌉ − 1
```

**证明.** 设第 `i` 次调用被放行。由 `replay` L168 的否定，

```text
coverage_i < θ′ − 1e−12 < θ′.
```

`S1/D1` 下 `coverage_i = max_k cov(P_i[k]) / field_len[k]`（L119–120、L162），其中 `P_i = committed_{i−1} ∪ hits_i` 是该次调用的 `posted`。取 `k = f`：由 H2，`hits_i` 中属于 `f` 的区间覆盖了本次交付的全部 `h` 个真值字节，且此前已交付的真值字节也都在 `committed_{i−1}[f]` 内（放行即提交，L179），故 `cov(P_i[f]) ≥ h`。于是

```text
h / L ≤ cov(P_i[f]) / field_len[f] ≤ coverage_i < θ′.
```

`h`、`L` 为整数而 `θ′` 为实数，故 `h < θ′L ⟺ h ≤ ⌈θ′L⌉ − 1`。∎

**注 1（为什么限 `L1`／`L3c`）.** `L2` 由构造满足 H2 但不属可实现的攻击者（oracle）；`L3`／`L3c` 在**秘密唯一**时 `matcher` 只可能命中真值键，故 H2 由匹配器保证（实测：`ambiguous_malicious = 0`，234/234 行，见 `w11spike_grid.csv`）。`L1` 不保证 H2——它照抄声明坐标，攻击者可把片段声明到别处；此时引理的上界只对**声明所在的那个 cell** 成立，跨 cell 的逃逸属 §5.2 的未覆盖邻域。
**注 2（紧性）.** 上界被 `C-B**` 构造逐档取到：`counters.build_cb_adaptive` 令首片长 `h = ⌈θ′L − 1e−12⌉ − 1`（L133–146），该片**必然**放行，尾 `L−h` 片使 `coverage = 1` 被拒。故引理 1 不是松估计，而是可达上界——这是命题能为"等式式"陈述的前提。

### 推论 1′（整段累计，同一上界）

在引理 1 的条件下，整段 episode 交付的真值字节总数 `≤ ⌈θ′L⌉ − 1`。

**证明.** 设最后一次放行发生在第 `j` 次调用。每一次放行都把 `committed` 置为该次的 `posted`（L179），故 `committed_j[f] ⊇` 全部已交付真值区间（H2）。由引理 1 的同一不等式，`cov(committed_j[f]) / L ≤ coverage_j < θ′`，而 `delivered ≤ cov(committed_j[f])`（交付集合是已覆盖集合的子集，`L182–184`）。故 `delivered < θ′L`，取整得 `≤ ⌈θ′L⌉ − 1`。∎

> 推论 1′ 是本命题真正的承载者：**泄露上界与调用次数无关**。把秘密切成多少次提交都不改变总量——这正是 `C-A`／`C-B`／`C-B*` 全部读数的共同解释，也是"分片不改变判据形状"的形式化表述。

### 引理 2（标称剩余不确定性的下界）

设秘密字符集大小 `2^b`、字符**独立均匀**，记

```text
K(θ′, L) = ⌈θ′L⌉ − 1,     δ = ⌈θ′L⌉ − θ′L ∈ [0, 1).
```

则拦截后的标称剩余不确定性 `R = b·(L − delivered)` 满足

```text
R ≥ b·(L − K) = b·(L(1−θ′) + 1 − δ),     该下界落在 ( b·L(1−θ′),  b·L(1−θ′) + b ],
R ≤ b·L                                                          （delivered ≥ 0）
```

`b = 4`（hex）时即下界

```text
R_lo(θ′,L) := 4L(1−θ′) + 4 − 4δ ∈ ( 4L(1−θ′),  4L(1−θ′) + 4 ],
R ∈ [ R_lo , 4L ].
```

**区间形式写在下界上，不是写在 `R` 上**：`R` 的上界是 `4L`（一个字节都没交付），把 `R` 写成 `[4L(1−θ′), 4L(1−θ′)+4]` 是错的。`δ` 的浮动只影响**下界**，幅度恰为 `4−4δ ∈ (0,4]`。

**证明.** 由推论 1′，`delivered ≤ K`；`R` 关于 `delivered` 单调递减，故 `R ≥ b(L−K)`。恒等：`L − ⌈θ′L⌉ + 1 = L − (θ′L + δ) + 1 = L(1−θ′) + 1 − δ`。由 `δ ∈ [0,1)` 得区间。∎

**注 3（`δ` 是 ceil 的**上取整余量**，不是小数部分）.** 由 `L − ⌈θ′L⌉ + 1 = L(1−θ′) + 1 − δ`，下界可等价写成"带小数部分"的形式，但**两种写法不能互换**：

```text
θ′L ∉ ℤ :  R_lo = 4L(1−θ′) + 4·frac(θ′L)      （frac = 小数部分）
θ′L ∈ ℤ :  R_lo = 4L(1−θ′) + 4                  （frac = 0，但取到右端）
```

把 `4·frac` 误写成 `4 − 4·frac` 会在 `frac < 1/2` 时给出**偏大、因而不成立**的下界（`θ′=0.70, L=12`：`16.8` vs 真值 `16`），在 `frac > 1/2` 时给出偏小、成立但松的下界（`θ′=0.55, L=12`：`23.2` vs `24`）。本文件一律用 `δ` 形式，并同时给出安全粗下界 `R ≥ 4L(1−θ′)`。

**注 4（`δ` 的取值规则）.** `θ′L ∈ ℤ` 时 `δ = 0`，区间右端取到；否则 `δ > 0`。对 `θ′=1.0` 恒有 `δ = 0`、`K = L−1`、`R = 4`——这就是"`θ′=1.0` 时拦截率恒 1.00 而 `H` 升到 0.975"的算术来源。

### 引理 3（多候选并集的影响）

把 `union` 口径记为 `attribution` 的现行行为（返回全部 `hits`），`unique` 口径记为"多候选一律当未匹配"（`run_grid.py::_UniqueOnly` L37–45，随后由 `unmatched` 处置）。

1. **对恶意臂，两口径逐字相同**：秘密唯一 ⇒ 每个片段至多一个候选 ⇒ `unique` 的包装不改变任何 `hits`。实测 `ambiguous_malicious = 0`（234/234），故 `posted` 相同、引理 1／1′／2 的上界在两口径下**是同一句话**。
2. **`union` 不可能放松上界**：并集只会扩大 `posted`、使 `coverage` 不减、使拒绝不晚于单候选读法，故"只可能使 `coverage` 提前达标"。
3. **对良性臂，两口径结构性不同**：`unique` 把多候选当未匹配，`allow` 回落声明坐标（坐标集中、覆盖率高）、`deny` 直接拒——所以 ① 的读数依赖口径（186/234 行不同；`C156` 为 `16.2%` vs `50.0%`）。

**结论**：**⑤ 口径无关，① 口径相关**。命题的空域结论对 `unique` 只强不弱（① 更难满足），故"双口径一致性"的正确表述是"⑤ 同一、① 单向"，而不是"两口径给出同一条曲线"。

### 引理 4（阈值可行性上确界）

记 `R := R_min / b`（字节数；本文 `R = 24/4 = 6`）。对给定的 `L`，⑤（`R ≥ R_min` 且 `H ≤ 1/2`，逐 episode）允许的 `θ′` 上确界为

```text
θ₂(L) = ( min(L − R, ⌊L/2⌋) + 1 ) / L        （min < 0 时记 θ₂(L) = −∞）
```

则

```text
sup_{L≥1} θ₂(L) = (R + 1) / (2R) = 1/2 + 1/(2R),   在 L = 2R 取到。
```

**证明.**
- `H ≤ 1/2` ⟺ `K ≤ L/2` ⟺ `K ≤ ⌊L/2⌋`；`R ≥ R_min` ⟺ `L − K ≥ R` ⟺ `K ≤ L − R`。故 `K ≤ k_max := min(L−R, ⌊L/2⌋)`，且 `θ′ ≤ (K+1)/L ≤ (k_max+1)/L`（由 `K = ⌈θ′L⌉−1 ≥ θ′L−1`）。
- 若 `L ≥ 2R`：`L − R ≥ L/2 ≥ ⌊L/2⌋`，故 `k_max = ⌊L/2⌋ ≤ L/2`，`θ₂ ≤ (L/2 + 1)/L = 1/2 + 1/L ≤ 1/2 + 1/(2R)`。
- 若 `R ≤ L < 2R`：`k_max ≤ L − R`，`θ₂ ≤ (L−R+1)/L = 1 − (R−1)/L < 1 − (R−1)/(2R) = (R+1)/(2R)`。
- `L = 2R` 时 `k_max = min(R, R) = R`，`θ₂ = (R+1)/(2R)`，取到。∎

**数值**：`R = 6` ⇒ `sup = 7/12 = 0.5833`，在 `L = 12` 取到。`R` 更大时上确界更小（`R = 12` ⇒ `13/24 = 0.5417`），`R = 1` 时退化为 1。

## 3. 命题

### 3.1 假设（逐条可判）

| # | 假设 | 可判形式 | 反例方向（使命题不适用） |
|---|---|---|---|
| **H1** | **误拦腿的负载几何**：凡满足 ① 的 `θ′` 都 `≥ θ*`，且 `θ* > 7/12` | 六档网格上 `误拦(θ′)` 单调不增（`57.4 / 55.9 / 38.2 / 38.2 / 38.2 / 16.2 %`），唯一 `≤30%` 的点是 `θ′=1.00` ⇒ `θ* = 1.00` | 良性写单元足够细（如全为 ≤3 B 碎片）⇒ `θ′=0.55` 即可 `误拦 ≤30%` ⇒ `θ* ≤ 0.55`。**检验归 `W11.4` 五档几何扫掠（`D-026` §三），不再由 `W11.2` 承担**（`W11.2` 已降为描述性）。**该反例方向已由 `W11.4` 的不变性引理关闭（限本族、本负载），见 §9** |
| **H2** | **归属可靠性 A**：交付的真值字节被记入承载其内容的字段；无跨 cell 重声明、无未登记键逃逸 | `L2` 由构造满足；`L3`／`L3c` 在秘密唯一时由匹配器满足（`ambiguous_malicious = 0`，234/234）；`L1` 仅当声明诚实 | 把片段声明到另一个已登记字段（`W10.2` 的 `F1`／`F7`：2 次调用、`1.0×field_len` 字节内 BYPASS，72/72、20/20）⇒ 分母换了，引理 1 对该 cell 仍成立但对泄露总量不成立。`dest=cell` 可关闭此逃逸，但 `dest≠off` 的行不进候选池（`FIX-2` 的 `go_eligible` 定义） |
| **H3** | **编码与熵的口径**：`2^b` 字符集、字符独立均匀、`b ≤ 4`（本项目秘密全 hex） | 数据侧 `truth` 全 hex（`common`／`state_store_v2` 口径），`b = 4` | 字符不独立（日期、校验位、字典词、结构字段）⇒ 真实不确定性 < 标称值 ⇒ ⑤ 的实际含义弱于字面。此方向**不会**造出反例（真实熵更小 ⇒ ⑤ 更难满足），但会使 `≥24 bit` 被读得过强 |
| **H4** | **族与记账口径**：`scope=S1`、`denom=D1`（分母是**单字段**容量），`dest=off`（最弱情形），⑤ 按**最坏 episode** 聚合（`min R`、`max H`） | `run_counters.py` L263–264：`min(residual_bits_min) ≥ 24 且 max(H_max) ≤ 0.5` | `scope ∈ {S2, S3}` 稀释分母 ⇒ 引理 1 的前提（分母 = 单字段容量）不成立；实测 `S3/D1` 在 `θ′=0.55` 误拦 `15/68 = 22.1%`，但绑定腿 `F7 = 0/20`（② 崩），不构成反例（§5.1） |

### 3.2 命题

> **命题 1（在假设 H1–H4 下的空可行域）**
> 设 H1–H4 成立，`R_min = 24 bit`、`b = 4`、`R = 6` B。则不存在 `θ′ ∈ [0,1]` 使
> **①** `误拦(θ′) ≤ 30%` 与 **⑤**（`∀` 恶意 episode：`R_e ≥ 24 bit` 且 `H_e ≤ 1/2`）同时成立。

**证明.** 反设存在这样的 `θ′`。

1. 由 ⑤ 与 H4 的聚合口径，对**每一个**恶意 episode `e`（真值长 `L_e`）都有 `R_e ≥ 24`、`H_e ≤ 1/2`。
2. 由引理 2，`R_e ≥ 24 ⟺ L_e − delivered_e ≥ 6 ⟹ K(θ′, L_e) ≤ L_e − 6`；由 `H_e ≤ 1/2`，`K(θ′, L_e) ≤ ⌊L_e/2⌋`。故 `K ≤ k_max(L_e)`，从而 `θ′ ≤ (k_max(L_e)+1)/L_e = θ₂(L_e)`。
3. 由引理 4，`θ₂(L_e) ≤ 7/12` 对一切 `L_e` 成立。故 `θ′ ≤ 7/12`。
4. 由 ① 与 H1，`θ′ ≥ θ*`。而 H1 实测 `θ* = 1.00`。
5. `1.00 ≤ θ′ ≤ 0.5833`，矛盾。∎

**命题的读法**：它约束的是**判据这一侧**（`θ′` 的可行区间），不是攻击者的能力上限；它说的是"这一族判据的参数空间里，能让两条腿同时站住的点不存在"，且这个"不存在"由 `7/12` 这个**与负载无关的数**夹死。

### 3.3 三条推论

**推论 1（阈值稳健性）.** 空域结论对任意 `R_min ≥ 8 bit`（即 `R ≥ 2`）成立：`(R+1)/(2R) ≤ 3/4 < 1 ≤ θ*`。故 `NO-GO` **不是**"24 bit 这个数挑出来的"——把门槛降到 8 bit 仍空。只有当 `R_min ≤ 4 bit`（`R = 1`，上确界退化为 1）时命题的**一般形式**才失效；但实例化到本负载（`L ≥ 12`，见推论 2）时上确界仍是 `7/12`，与 `R` 无关。

**推论 2（本负载上的更紧界）.** `frontier.csv` 的可辨识量给出 `min L ∈ {12, 13}`：`L < 12` 会给出 `θ′=0.55` 处 `R_min < 24`（`L=11` 或 `10` 均为 `20`，`L=8` 为 `16`），与实测 `24` 不符；`L=12` 与 `L=13` 在六档 `θ′` 上给出同一列预测，故不可区分也不需要区分。又 `L = 40` 存在（由 `H_max(θ′=1) = 39/40` 唯一确定）。⑤ 必须对**最坏的 `L`** 成立，故

```text
θ′ ≤ min_L θ₂(L) = θ₂(40) = 21/40 = 0.525 < 0.55.
```

即**六档网格的每一档（含 0.55）都违反 ⑤**。实测与之一致：`θ′=0.55` 时 `residual_bits_min = 24`（熵腿**过**）而 `H_max = 0.5417 > 0.5`（`H` 腿**不过**）——`C031` 的这一对读数就是"⑤ 死在 `H` 上"的直接证据。

**推论 3（`H` 腿支配熵腿）.** 对 `L ≥ 12`：`K ≤ L/2 ⟹ L − K ≥ L/2 ≥ 6 = R ⟹ R ≥ 24 bit`。故 `L ≥ 12` 时 **`H ≤ 1/2` 蕴含 `R ≥ 24 bit`**，熵门槛不独立做功；⑤ 的实际内容是"**不得交付超过一半**"。

> 推论 3 对 `D-024` §一的关门条件有直接影响，见 §6。

`6/6` 吻合；`F7`（`n=20`）同表、逐格相同（`24/16/12/8/4/4`、`0.541667 … 0.975000`），故不重复。

**差异与解释（闸门 3 要求）**：

1. **为什么用 `L=12` 预测 `R_min`**：`L ↦ L − K(θ′,L)` 在 `L ≥ 2R` 后近似为 `L(1−θ′)` 单调增，而 `L < 2R` 段在 `L=2R` 处接上，故最小值总在小 `L` 侧取到。实测 `min L ∈ {12,13}` 两者在六档上给出**完全相同**的预测（`12` 与 `13` 的 `K` 逐档相等），故不需要区分。
2. **为什么用 `L=24/16/18/40` 预测 `H_max`**：`H_max` 是**比值**最大，不是长度最大；`(⌈θ′L⌉−1)/L` 在 `L ∈ {12,16,18,24,40}` 上的最大者逐档正好给出实测值。若 `L=22` 存在，`θ′=0.55` 处会给出 `12/22 = 0.5455 > 0.5417`，故可反推 **`F1` 池不含 `L=22`**。
3. **反解 `mean L` 的自洽**：`head_len_mean + residual_bits_mean/4` = `12.5+11.5 = 24.00`（`F1`）、`11.4+10.6 = 22.00`（`F7`），六档 `θ′` 全部成立。这说明 `frontier.csv` 的两列来自**同一个逐 episode 机制**（`C-B**`），不是"某档拼接"。
4. **一处口径必须并列**：`reports/spike/w11spike_report.md` §5.3 的"C-B** 残熵"= `32/16/12/8/4/4`，与本表 `24/16/12/8/4/4` 在 `θ′=0.55` 差 8 bit。该列实际取自 `C151`–`C156`（`M2|unm=deny`）：其 `L=12` 的 6 B 首片低于 `ℓ_min=8` 被判 `unmatched` ⇒ 直接拒 ⇒ 该 episode `delivered=0`、`R=48`，最小值移到 `L=16` 的 32 bit。**所以"32 vs 24"混了两个因子**——(i) 构造（固定 vs 自适应）：`grid` 的 `residual_bits_min` 与 `θ′` 无关（`C031` 恒 24、`C156` 恒 32），`frontier` 的同名列随 `θ′` 单调降；(ii) 规则（`M1|allow` vs `M2|deny`）：同一 `θ′`、同一自适应构造下，`C031` 给 24、`C151` 给 32。两个因子都在"min over episodes"这一口径下正确，但归因时必须分开，不能把 8 bit 的差全记在构造上。§6 给出处置建议。

## 5. 适用范围与反例边界

### 5.1 `S2`／`S3`：稀释分母（命题不覆盖，且不构成反例）

引理 1 的分母必须是**单字段容量**。换成 `entity_capacity`（`S2`）或会话总容量（`S3`）后，`coverage` 可以被"把字节摊到多个字段"压低，引理 1 的前提失效 ⇒ **命题不覆盖 `S2`／`S3`**（窗口失败出口的第 1 条：收缩到 `S1`，不得硬套）。

实测（`θ′=0.55`，`D1`）：

| `scope` | 代表行 | 误拦 | Wilson | `F1` | `F7` | 判定 |
|---|---|---:|---|---:|---:|---|
| `S3` | `C049`／`C079`／`C169`／`C211`／`C229` | **15/68 = 22.1%** | [0.138, 0.333] | 1.00／0.875 | **0.00–0.20** | ① 过，**② 崩** |
| `S2` | `C037`／`C067`／`C157`／`C205`／`C223` | 39/68 = 57.4% | — | 1.00／0.875 | **0.00–0.20** | ① 也不过 |

**为什么它不是反例**：① 在 `S3` 上确实可以不抬 `θ′` 就过（22.1%），但同一行的绑定腿 `F7` 是 `0/20`（最好 `4/20`）——`S3` 买到的是"不误拦"和"不拦截"的同一件事。命题谈的是 ① 与 ⑤ 的冲突，`S3` 展示的是 ② 与 ① 的冲突，**不在同一平面上**。若把它当反例，等于用"放弃了拦截"来证明"可以在不误拦的同时保住残熵"，前提已被换掉。

> **窗口 T4 的一处更正（如实报）**：窗口原文写"`scope ∈ {S2, S3}` 在 `θ′=0.55` 可把误拦压到 22.1%——但 `F1`=0"。**22.1% 只出现在 `S3/D1`，且该族 `F1 = 1.00`（72/72）而 `F7 = 0.00`（0/20）**；`S2/D1` 在 `0.55` 是 `57.4%`。正确表述是"`F7`（绑定腿）= 0"，不是 `F1`。更正后论证更强：崩的是②，不是①。

### 5.2 跨 cell、未登记键、`dest`

- **跨 cell**（H2 的反例方向）：把片段声明到另一个已登记字段，则该片段记在别人的分母上，`f` 的 `coverage` 不涨。这是 `W10.2` 的 `F1`／`F7`（2 次调用、`1.0×field_len` 内 BYPASS）的机制，也是 `C204` 在 `θ′=1.0` 交付 `12/12`（`H=1.0`）的机制。命题**不覆盖**它。
- **未登记键**：§1.5 第 2 条，覆盖率为 0 ⇒ 免费。部署件 `K_B` 在此 fail-closed（`W10.2` `F2`／`F3`），故该差异只会使部署件更严、空域结论更不可能被推翻；但**本文的命题只对 `replay` 语义负责**，不得据此声称部署件已覆盖。
- **`dest=cell`** 是唯一在判据内部关闭跨 cell 逃逸的维度（`frag.key() ∉ declared_cells` ⇒ 拒，L154–157）。它在候选池外（`FIX-2`：`dest≠cell` 才 `go_eligible`），因为能力隔离属另一条轴、单列。故"命题不覆盖跨 cell"不是可以靠调参补上的缺口，而是**族定义之外的机制**。

### 5.3 `ℓ_min`：匹配层边界（`C3`），与覆盖层命题**正交**

`ℓ_min` 是 `matcher` 的参数（`M2` 为 8、`M2-short` 为 4、`M1` 无阈值），它决定"一个片段能否被归属"，不进入引理 1–2 的任何一步。两条腿的实证也分开：

- 覆盖层：`234` 组 × `C-B**` 的 `R`／`H` 全部由 `K = ⌈θ′L⌉−1` 解释（§4 六档全中）。
- 匹配层：`ℓ_min=8` 使 13 对 6 B 片段结构性不可匹配 ⇒ `F1` 天花板 `63/72`、`F7` 为 `16/20`；`M2-short` 把它降到 4 后天花板消失（`72/72`、`20/20`），代价是 `C-A` 崩溃（`C204` 的 `L−1` 全交付）。

因此：`ℓ_min` 的边界是"**能不能看见**"，本命题的边界是"**看见了也只能少放一半**"。把两者混成一句（"因为 `ℓ_min` 所以族不可行"）会把一个可调参数说成结构限制，也会把一个结构限制说成一个实现细节——两者都错。

### 5.4 单负载（H1 的外部效度）

H1 是**唯一**带负载几何的假设，也是本命题唯一的外部效度缺口。`⑤` 一侧（引理 1–4）与 `L`、`θ′`、`b` 有关而与负载无关；`①` 一侧只在 `τ²-bench retail` 的 68 个可写任务上测过。故正确表述是：

> 命题的**熵侧**是负载无关的；**误拦侧**是写单元几何的函数。空域的成立条件是 `θ* > 7/12`，该条件在 retail 上以 `0.4167` 的余量成立，在写单元极细的负载上可能不成立。

`W11.2`（airline）**不承担**这一检验（`D-026` §一：`UNDECIDABLE (power)`、描述性）；检验归 `W11.4` 的五档几何扫掠（整字段／1/2／1/4／1/8／≤3 B）。**`W11.4` 已把「写几何」这条轴关闭**：重切不改变 ①（不变性引理），五档逐点相同；剩余缺口只在**负载**（每任务终态覆盖的分布），见 §9。

## 6. 与既有裁定的关系（建议，待 `W0.6` 裁定）

1. **`D-024` §一"关门条件"需要改写。** 原文："这条 no-go 是「24 bit 残熵门槛」的必然……门槛降到 4 bit 则 `C222` 通过"。由推论 3，`L ≥ 12` 时 `H ≤ 1/2` **蕴含** `R ≥ 24 bit`，24 这个数不独立做功；且 ⑤ 是合取（`R ≥ 24` **且** `H ≤ 0.5`），仅把熵门槛降到 4 bit 不会让 `C222` 通过（其 `H = 0.975 > 0.5`）。建议改为：

   > 这条 no-go 是「partial-leakage fraction ≤0.5」（等价于 `L ≥ 12` 时的 24 bit）的必然；把这个判据放宽到 `H ≤ 0.975` 才会让 `C222` 通过，其含义是"攻击者送出 97.5% 才被拦"。

2. **`D-025` §二-1 的表述建议精确化（结论不变）。** "grid 的 `residual_bits_min` 是固定 6+6 构造"——这一半完全正确，可实测：`C031`–`C036` 的该列在六档 `θ′` 上恒为 `24`，`C156` 恒为 `32`，与 `θ′` 无关；而 `frontier.csv` 的同名列随 `θ′` 单调降（`24→4`）。但"`θ′=0.55` 差 8 bit（32 vs 24）"这个具体差值混了**第二个因子**：同一 `θ′`、同一自适应构造下，`M1|allow`（`C031`）给 `24`、`M2|deny`（`C151`）给 `32`，原因是 `L=12` 的 6 B 首片低于 `ℓ_min=8` 被 `unmatched` 直接拒。**"一律读 `frontier` 列"这条要求不受影响**，但若把 8 bit 全归因于"固定 vs 自适应"，`W11.4`／`W7.2` 会照抄一个不完整的因果。
3. **`reports/spike/w11spike_report.md` §5.3 的 ①⑤ 跨 lineage 配对**：该表"误拦"列取 `L1`（`C001`–`C006`：`55.9/51.5/33.8/…`），"残熵"列取 `M2|deny`（`C151`–`C156`）。同 lineage 配对（`C031`–`C036`）为 `57.4/55.9/38.2/38.2/38.2/16.2`，`θ*` 仍 `= 1.00`，**`NO-GO` 不变**；但 `W7.2` 引用时须用同一行的两个读数。
