## Highlights（每条 ≤85 字符，含空格；投稿系统单独填写）
1. None of 102 deployable coverage criteria meets both misfire and leakage bounds.
2. Benign misfire needs theta'>0.99; residual entropy >=24 bit needs theta'<=0.55.
3. Splitting writes finer changes nothing: the region is set by final coverage.
4. Minimum attributable fragment length (8 B) is a measurable boundary.
5. A second real workload shows the same direction, with too few tasks to quantify.
